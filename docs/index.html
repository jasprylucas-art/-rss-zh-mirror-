怎么加更多源？

  1. 打开仓库里的 feeds.txt，点右上角铅笔图标编辑
  2. 每行粘贴一个 RSS 地址（# 开头的行为注释）
  3. 提交后到 Actions → 翻译 RSS → Run workflow，约 1 分钟生效

自动更新

  1. 默认每小时第 17 分钟自动跑一次（GitHub 可能延迟几分钟）
  2. 公开仓库完全免费；私有仓库的定时会被 GitHub 在闲置 60 天后停用
